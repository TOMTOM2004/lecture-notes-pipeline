# 運用ルール

## 1. 基本方針

- `raw/` は原本保全層。編集しない
- `converted/` は再生成可能な中間層。原則編集しない
- `claude/` は最終的な作業層。人間編集可

## 2. 授業ディレクトリの命名

授業ディレクトリは `courses/` 配下に配置する。

| 授業名 | ディレクトリ名 |
|---|---|
| Example Course | `example-course/` |
| Another Course | `another-course/` |

命名規則:
- 授業ディレクトリ名は授業名をそのまま使う（日本語可）
- ファイル名は小文字ケバブケース（日本語不可）

## 3. ファイル命名規則

講義ファイルは講義番号を先頭に置く。

```
L01_guidance.pdf
L07_slides.md
L07_transcript_raw.md
```

- 講義番号は `L01`, `L02` の形式（2桁固定）
- 単語区切りはハイフン
- 日本語ファイル名は使わない（ただし授業ディレクトリ名は日本語可）
- 同じ講義番号を `raw/` / `converted/` / `claude/` で揃える

## 4. ノート構造

各講義ノートは `templates/lecture-note.md` に従う。

必須セクション:
- 概要
- レジュメ要点
- 授業での補足
- 重要用語
- 理解したこと
- 未理解点
- 関連リンク

## 5. glossary方針

- 用語は1ファイル1概念を原則とする
- 英語表記と日本語表記を併記する
- 類義語は冒頭で明示する
- 複数授業にまたがる用語は `shared/glossary/` に配置する

## 6. Git運用

コミットメッセージは Conventional Commits に従う。

| 操作 | prefix |
|---|---|
| 原本追加 | `add:` |
| 変換結果追加 | `convert:` |
| Claude整形 | `structure:` |
| 人間編集 | `annotate:` |
| 設定・ルール変更 | `chore:` |
