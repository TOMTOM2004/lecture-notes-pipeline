# 大学授業ノート管理基盤 要件定義

## 1. 目的

複数の大学授業の
授業資料・授業内容・復習ノートを一元管理し、
講義理解・試験対策・将来的な知識再利用を可能にする。

## 2. 対象情報

- 配布レジュメPDF
- 授業録音音声（利用可の場合のみ）
- PDF変換結果（Markdown / JSON）
- 音声文字起こし結果
- Claude Codeによる整形済みノート
- 用語集
- 復習ノート

## 3. スコープ

### 3.1 対象

- 授業レジュメの保存
- PDF→Markdown/JSON変換
- 音声→Transcript変換
- Claude Codeによる整形
- 人間による追記編集
- 授業ごとの glossary と review の蓄積
- 複数授業横断の共通 glossary / references 管理

### 3.2 非対象

- 完全自動での100%正確なノート生成
- 大規模OCRが前提のスキャン文書処理

## 4. 成果物

- 各回の講義ノート（授業ごと）
- 用語集（授業ごと・横断共通）
- 中間/期末向け復習ノート
- 要件定義・運用ルール文書

## 5. データ階層

### 5.1 raw

原本保全層。編集禁止。

- 配布PDF
- 音声（Git管理外）
- シラバス

### 5.2 converted

機械変換層。原則手修正禁止。

- PDF Markdown
- PDF JSON（Claude API入力用）
- transcript raw
- logs

### 5.3 claude

作業層。Claude Code整形後、人間編集可。

- lectures（+ STATUS.md で処理状態管理）
- glossary（必要時のみ作成）
- reviews（必要時のみ作成、`/make-review` で生成）
- figures（必要時のみ作成、スライド図の再現用）
- scratch（Git管理外、必要時のみ作成）

## 6. 機能要件

### FR-01 原本保存

配布資料PDFと音声ファイルを raw に保存できること。

### FR-02 PDF変換

PDFからMarkdownおよびJSONを生成し、converted に保存できること。

### FR-03 transcript保存

音声から文字起こし結果を生成し、converted/transcript_raw に保存できること。

### FR-04 Claude Code整形

converted 内の Markdown / JSON / transcript を入力として、
claude/lectures に整形済みノートを生成できること。

### FR-05 用語抽出

講義ノートから重要用語候補を抽出し、claude/glossary に反映できること。

### FR-06 復習ノート生成

各回ノートをもとに中間・期末向けのレビュー資料を生成できること。

### FR-07 人間編集

claude 配下のファイルは人間が追記・修正できること。

### FR-08 複数授業管理

courses/ 配下に新ディレクトリを追加するだけで新授業を管理できること。

### FR-09 横断共通リソース

複数授業に登場する用語・参照資料を shared/ で一元管理できること。

## 7. 非機能要件

### NFR-01 可読性

最終ノートはスマホでも閲覧しやすいMarkdown形式であること。

### NFR-02 再現性

raw と converted を保持し、Claude Code後の内容が後から追跡可能であること。

### NFR-03 保守性

講義1回ごとの追加が既存構成を壊さず実施できること。

### NFR-04 一貫性

ファイル命名規則と見出し構造が統一されていること。

### NFR-05 ローカル中心

主要処理はMacローカル環境で実行できること。

### NFR-06 拡張性

新授業の追加がディレクトリ作成だけで対応できること。

## 8. 運用ルール

- Rule-01: raw は編集しない
- Rule-02: converted は原則手修正しない
- Rule-03: claude は人間編集可
- Rule-04: 同一講義番号で全層を対応させる
- Rule-05: glossary は重複定義を避ける
- Rule-06: Claude Codeの再実行で作業版を安易に上書きしない
- Rule-07: 音声ファイルは Git に含めない

## 9. 品質基準

以下を満たせば、その講義回の処理は合格とする。

- 見出し階層が読める
- 箇条書きが崩れていない
- 表が意味を保持している
- 授業補足がレジュメ要点と分離されている
- 重要用語が明示されている

## 10. 今後の拡張候補

- glossary 自動リンク
- 重要度タグ付け
- 試験頻出論点抽出
- 横断レビュー自動生成
- 授業間の概念リンク
