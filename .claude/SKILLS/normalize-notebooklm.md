## 使い方

```
/normalize-notebooklm
```

対象授業と講義番号を指定してください（例: `example-course L00`）。

## 入力フォーマットについて

NotebookLMのverbatim（一言一句）出力は **単語をスペースで区切った形式** になる。

```
はい え それ では え 第 1 回 の 講議 を 開始 さ せ て いただき たい と 思い ます
```

このため整形作業の量はWhisperより大きい（フィラー除去500〜2000件、誤変換40〜100件程度）。
ファイルサイズが大きい場合（10,000行超）はoffset/limitを使って分割して読み込む。

## 処理手順

1. `courses/{course}/converted/transcript_raw/` から `L{NUM}` で始まるファイルをすべて読み込む

2. `courses/{course}/converted/pdf_md/L{NUM}_*.md` をすべて読み込む（専門用語の照合・補正に使う）

3. トランスクリプトを以下の順で整形・補正する:

   **a. NotebookLM前置き文の除去（ある場合のみ）**
   「ご提示いただいたソース資料に基づき〜一言一句すべて書き起こします。」のようなメタ的な前置き文が冒頭にある場合は削除する。ない場合はスキップ。

   **b. 単語スペース区切り → 自然な日本語文章への変換**
   スペース区切りの単語列を自然な日本語の文章に結合する。
   - 句点（。）で文を終わらせ、適切な箇所で読点（、）を入れる
   - この段階でフィラー語も同時に除去する（下記c参照）
   - **要約・言い換えは絶対にしない。発言の意味・内容は一切変えない**

   **c. フィラー語・言い直しの除去**
   口語特有のノイズを除去する。実績として多い順:
   - 「え」「えー」「えっと」「ええ」（最多 — 文頭・文中に頻出）
   - 「あの」「あ」
   - 「ま」「まあ」（単独で意味を持たない場合）
   - 「なんか」「ちょっと」（単独用法のみ）
   - 言い直し・繰り返し: 同じ内容を直後に言い直している箇所

   **d. 文字レベルの誤変換補正**
   NotebookLM verbatimは同音の漢字を誤変換することが多い。PDF資料の表記を正とする。
   頻出パターン（参考）:
   - 「使名」→「使命」／「期源」→「起源」／「講議」→「講義」
   - 「版書」→「板書」／「事業内」→「授業内」のような授業頻出語の同音誤変換
   - 授業の専門用語が同音の別漢字に化けるパターン（PDF資料の表記と照合して補正）
   - 話者名の誤変換（同音の別漢字に化けるパターン）
   - 判断できない箇所は修正しない

   **e. 段落・見出しの挿入**
   話題が大きく転換する箇所に `##` 見出しを挿入し、適切な長さで段落を区切る。
   - 見出しのタイトルはPDF資料のセクション名を参照して付ける
   - 話題転換が明確でない場合は段落区切りのみ（見出しなし）でよい

4. 整形済みテキストを `courses/{course}/converted/transcript_corrected/` に保存する
   - ファイル名: 元ファイルの `_transcript_raw` を `_transcript_corrected` に置換
     例: `L00_lecture_transcript_raw.md` → `L00_lecture_transcript_corrected.md`
   - ファイル先頭に以下のメタ情報を追加する:
     ```
     <!-- corrected_at: {ISO日時} -->
     <!-- source: {元ファイルパス} -->
     <!-- method: notebooklm -->
     ```

5. `courses/{course}/claude/lectures/STATUS.md` の該当行を更新する
   - `converted` 列を ✅ にする
   - タイトルが空欄なら `pdf_md` の内容から補完する

## 注意事項

- `transcript_raw/` の元ファイルは上書きしない
- `corrections.json` は使用しない（Whisper専用）
- タイムスタンプ行の保護は不要（NotebookLM出力にはタイムスタンプがない）
- 出力先にすでにファイルがある場合は上書き前に確認する
- 保存後、以下を簡潔に報告する:
  - 除去・整理したフィラー語・繰り返しの件数（概数）
  - 補正した専門用語の件数と主な例
  - 挿入した見出し数
