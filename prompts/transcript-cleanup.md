# プロンプト: transcript整形

## 用途

`converted/transcript_raw/` の生文字起こしから授業補足情報を抽出する。

## プロンプト本文

```
以下は大学授業の音声文字起こし結果です。
講義ノートの「授業での補足」セクションに追加すべき情報を抽出してください。

【授業名】: {course}
【講義番号】: L{NUM}

【文字起こし】:
---
{transcript}
---

抽出のルール:
1. 冗長な口語表現・フィラー（えー、あのー、など）は除去する
2. レジュメに書いていない補足説明・例示を優先して抽出する
3. 教員が強調した点（「これは重要」「試験に出る」など）は必ず含める
4. 箇条書き形式で出力する
```
