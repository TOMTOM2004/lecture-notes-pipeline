# プロンプト: PDF→講義ノート変換

## 用途

`converted/pdf_md/` の生Markdown変換結果を `templates/lecture-note.md` の形式に整形する。

## プロンプト本文

```
以下は大学授業の配布レジュメPDFをMarkdownに変換した生出力です。
これを `templates/lecture-note.md` のフォーマットに合わせて整形してください。

【授業名】: {course}
【講義番号・タイトル】: L{NUM} {title}

【生出力】:
---
{raw_markdown}
---

整形のルール:
1. 見出し階層（H1→H2→H3）を適切に修正する
2. 箇条書きの崩れを直す
3. 表は意味が保持されるよう修正する
4. 「レジュメ要点」セクションにPDFの内容をまとめる
5. 「重要用語」セクションに登場した専門用語を抽出する
6. 「授業での補足」「理解したこと」「未理解点」は空欄のままにする
```
